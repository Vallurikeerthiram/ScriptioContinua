# Intermediate and Duplicate Data

This folder contains intermediate datasets and summaries used during the development of the final datasets.

## Files

- **`simple_wikipedia.xlsx`**: Initial collection of Wikipedia articles.
- **`Sentence_ScriptioCcntinua.xlsx`**: An early version of the scriptio continua sentence dataset.
- **`sentence_count_summary_non_empty_only.xlsx`**: A summary of sentence counts across the dataset.
