# 8000 Rows Dataset

This folder contains a smaller version of the scriptio continua dataset, consisting of approximately 8,000 processed sentences.

## Files

- **`Original_Articles.xlsx`**: The raw articles fetched from Simple Wikipedia.
- **`Processed_Articles_FINAL_MEANINGFUL.xlsx`**: The processed sentence-level dataset.
- **`FINAL_Split_By_ART_ID.xlsx`**: Dataset split by Article IDs.
- **`FINAL_Split_By_PARA_ID.xlsx`**: Dataset split by Paragraph IDs.
- **`FINAL_Split_By_SENT_ID.xlsx`**: Dataset split by Sentence IDs.
