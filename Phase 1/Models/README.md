# Deep Learning Models for Word Segmentation

This folder contains various deep learning architectures for character-level sequence labeling to achieve word segmentation.

## Architectures

- **Plain DL Models**: Standard neural network architectures (e.g., Bi-LSTM, GRU) used for character-level classification.
- **CRF-Based Models**: Neural architectures integrated with Conditional Random Fields (CRF) to better model sequence dependencies and constraints.

## Subdirectories

- **`plain DL models/`**: Training scripts and results for non-CRF models.
- **`DL models_CRF/`**: Training scripts and results for CRF-enhanced models.
- **`1st run/`**: Initial experimental results and early model versions.
- **`resul;ts/`**: Consolidated results from different model runs.
