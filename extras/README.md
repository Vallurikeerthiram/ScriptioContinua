# Extras: Utility Scripts

This folder contains utility scripts for post-processing model results and generating detailed metric workbooks.

## Scripts

- **`generate_metrics_workbooks.py`**: Automates the creation of comprehensive Excel workbooks summarizing the metrics from various model runs.
- **`add_avg_row_to_metrics_workbooks.py`**: A helper script to calculate and append average scores to the generated metrics workbooks.
