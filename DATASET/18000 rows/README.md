# 18000 Rows Dataset

This folder contains the larger version of the scriptio continua dataset, consisting of approximately 18,000 processed sentences.

## Files

- **`final_dataset_continuous_ids.xlsx`**: The master dataset with continuous IDs assigned to each entry.
- **`ART_based_split.xlsx`**: Dataset split based on Article IDs (ensures all sentences from a single article stay together).
- **`PARA_based_split.xlsx`**: Dataset split based on Paragraph IDs.
- **`SENT_based_split.xlsx`**: Dataset split based on Sentence IDs.
- **`new dataset/`**: A sub-directory containing further refinements, metrics, and debug results for this dataset.
