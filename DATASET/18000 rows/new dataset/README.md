# New Dataset Refinements and Metrics

This folder contains refined versions of the 18,000-row dataset along with evaluation metrics for various models.

## Key Files

- **`final_dataset_continuous_ids_meaningful_strict_ordered_renumbered.xlsx`**: A strictly ordered and renumbered version of the dataset.
- **`SENT_ID.xlsx`**: The core sentence-level dataset used for model evaluation.
- **Metric Results**:
  - `coh_metrics.xlsx`: Coherence-based metrics.
  - `gs_metrics.xlsx`: General/Gold Standard metrics.
  - `lm_metrics.xlsx`: Language Model-based metrics.
- **Result Files**:
  - `SENT_ID_coh_results.xlsx`
  - `SENT_ID_gs_results.xlsx`
  - `SENT_ID_lm_results.xlsx`
  - `SENT_ID_cm_results.xlsx`
- **ID Mappings**:
  - `ART_ID.xlsx`
  - `PARA_ID.xlsx`
