# Dictionaries and Trie Implementation

This folder contains the lexical resources used for dictionary-based word segmentation.

## Files

- **`universal_trie.py`**: A Python implementation of a Trie data structure optimized for fast prefix lookup and word identification.
- **`words_alpha.txt`**: A comprehensive list of English words (alphabetical only).
- **`english_dictionary.csv`**: A large English dictionary dataset.
- **`web_words_1M.txt`**: A list of common words from web corpora.
- **`mobypos.txt`**: Part-of-speech data for words, potentially used for linguistic validation.
