# Plain Deep Learning Models

This folder contains scripts for training and evaluating standard deep learning models for character-level classification.

## Files

- **`train_models.py`**: The main training script for various neural network architectures (e.g., RNN, LSTM, GRU).
- **`model_comparison_results.xlsx`**: Detailed performance metrics for the plain DL models.
- **`cmd.txt`**: Logs of commands executed during training.
