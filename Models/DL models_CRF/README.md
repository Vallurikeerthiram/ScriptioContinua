# CRF-Based Deep Learning Models

This folder contains scripts for training and evaluating deep learning models with a Conditional Random Field (CRF) top layer. CRFs are particularly effective for sequence labeling tasks like word segmentation as they account for the dependencies between neighboring labels.

## Files

- **`train_models_CRF.py`**: The main training script for CRF-based architectures.
- **`model_comparison_results_CRF.xlsx`**: Detailed comparison of different CRF model configurations.
- **`LLmodels/`**: Subdirectory likely containing saved model weights.
- **`cmd.txt`**: Logs of commands executed during training.
