# Telugu Sample Dataset Results with Metrics

This directory contains evaluation workbooks recording performance scores for the initial 100-article Telugu prototype experiments.

---

## Files

- **`telugu_2state_scores.xlsx`**: Performance metrics (macro F1, accuracy, BLEU, ROUGE, BERTScore) for 2-state models (BiLSTM, CNN, GRU, RNN) on the sample dataset.
- **`telugu_4state_scores.xlsx`**: Performance metrics for 4-state BIES models on the sample dataset.
- **`telugu_4state_crf_scores.xlsx`**: Performance metrics for 4-state BIES models decoded with Linear-Chain CRF on the sample dataset.
